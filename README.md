# 🌾 NPSS Bot - National Pest Surveillance System

एक स्मार्ट कृषि और बागवानी सहायक चैटबॉट जो किसानों को कीट प्रबंधन, फसल सलाह और बागवानी जानकारी प्रदान करता है।

## 🎯 विशेषताएं

- ✅ **कीट पहचान और नियंत्रण** - विभिन्न कीटों के लिए उपचार
- ✅ **फसल सलाह** - फसलों की खेती के बारे में जानकारी
- ✅ **बागवानी जानकारी** - फल, सब्जी और फूलों की फसलें
- ✅ **24/7 चैट सहायता** - तुरंत जवाब पाएं
- ✅ **हिंदी और अंग्रेजी** - दोनों भाषाओं में समर्थन
- ✅ **उत्तरदायी डिजाइन** - सभी डिवाइसों पर काम करता है

## 📱 चैटबॉट क्षमताएं

NPSS Bot निम्नलिखित विषयों पर सलाह देता है:

| विषय | विवरण |
|------|--------|
| 🌶️ **मिर्च** | बीज दर, दूरी, सिंचाई, कीट नियंत्रण |
| 🍅 **टमाटर** | तापमान, मिट्टी, रोग प्रबंधन |
| 🥭 **आम** | जलवायु, रोपण, कीट नियंत्रण |
| 🥔 **आलू** | बीज दर, फसल अवधि, उपज |
| 🐛 **कीट नियंत्रण** | जैविक, रासायनिक और यांत्रिक तरीके |
| 💧 **सिंचाई** | मौसम के अनुसार जल प्रबंधन |
| 🌱 **खाद और पोषण** | जैविक और रासायनिक खाद |
| 🌻 **फूलें** | गुलाब, गेंदा, चमेली की खेती |
| 🌍 **मिट्टी प्रबंधन** | मिट्टी तैयारी और परीक्षण |

### स्थानीय रूप से चलाएं
1. इस रिपोजिटरी को क्लोन करें:
   ```bash
   git clone https://github.com/mohdashif6995/npss-bot.git
   ```

2. डायरेक्टरी में जाएं:
   ```bash
   cd npss-bot
   ```

3. `index.html` को अपने ब्राउज़र में खोलें:
   ```bash
   # Windows
   start index.html
   
   # Mac
   open index.html
   
   # Linux
   xdg-open index.html
   ```
